# القضية رقم 001 — أين اختفت الهمّة؟

عرض تقديمي تفاعلي سينمائي باللغة العربية (RTL)، مستوحى من مكتب تحقيقات قديم.
يتكوّن من 12 شريحة مستقلة بملء الشاشة، مع تنقّل سلس و animations و مؤثرات صوتية اختيارية.

---

## التشغيل محليًا باستخدام VS Code + Live Server

1. افتح المجلد في **Visual Studio Code**.
2. ثبّت إضافة **Live Server** (من معرض الإضافات:بحث عن `Live Server` ثم Install).
3. انقر على الزر **Go Live** في أسفل يمين نافذة VS Code.
4. سيفتح المتصفح تلقائيًا على الرابط `http://127.0.0.1:5500`.
5. إذا لم تفتح الصفحة تلقائيًا، افتح `index.html` بالضغط عليه بزر الفأرة الأيمن ← **Open with Live Server**.

> **تنبيه:** لا تفتح الملف بالنقر المزدوج فوق `index.html` (بروتوكول `file://`)، لأن بعض المتصفحات تمنع تحميل الخطوط والموارد. استخدم Live Server دائمًا.

## بنية المشروع

```
.
├── index.html              # هيكل العرض والشرائح الاثنتي عشرة

│   ├── base.css            # الألوان، الخطوط، الخلفيات، الأزرار

├── js/
│   ├── vendor/gsap.min.js  # GSAP 3.12.5 (نسخة محلية، لا يتطلب إنترنت)
│   ├── data.js             # كل نصوص العرض والمحتوى
│   ├── audio.js            # أصوات مُولّدة عبر Web Audio API
│   ├── animations.js       # حركات الدخول والخروج لكل شريحة
│   └── app.js              # التحكم والتنقّل والتفاعلات
└── assets/textures/        # خامات SVG محلية (ورق، فلّين، خشب، جلد، خريطة)
```

## طريقة التنقّل

| الوسيلة | الإجراء |
|---|---|
| زر **التالي** / **السابق** | التنقّل بين الشرائح |
| `→` أو `Space` أو `Page Down` | الشريحة التالية |
| `←` أو `Page Up` | الشريحة السابقة |
| `Home` / `End` | أول / آخر شريحة |
| زر **القائمة** أو `M` | فتح قائمة الشرائح والقفز لأي شريحة |
| زر **ملء الشاشة** أو `F` | تفعيل/إلغاء ملء الشاشة |
| زر **إعادة العرض** | العودة للشريحة الأولى |
| السحب بالإصبع (يمين/يسار) | التنقّل على الجوال والتابلت |
| `Esc` | إغلاق القائمة أو النافذة المنبثقة |

## التفاعلات

- **الشريحة 5**: اضغط على أي بطاقة مشتبه به لفتح ملف التحقيق الخاص به.
- **الشريحة 6**: اضغط على أي بطاقة دليل لفتح نافذة تفاصيلها.
- **الشريحة 12**: أجب عن الأسئلة الثلاثة واكتب التزامك الشخصي، ثم اضغط **طباعة الالتزام**.
  تُحفظ إجاباتك تلقائيًا في المتصفح، وتظهر في ورقة طباعة أنيقة بتصميم ملف سري.
- **زر الصوت**: يفعّل أجواءً صوتية هادئة وأصوات تنقّل (مولّدة برمجيًا، بلا ملفات صوت).
- **زر تقليل الحركة**: يعطّل الحركات احترامًا لتفضيل النظام `prefers-reduced-motion`.

## الاقتباسات والمصادر

جميع الاقتباسات في شريحة «ملفات أصحاب الهمم» موثّقة ومذكورة مصادرها داخل الواجهة:

- الإمام النووي — من مقدمة شرح النووي على صحيح مسلم.
- ابن الجوزي — كتاب «المدهش»، ص 364–365.
- عمر بن عبد العزيز — يُروى في «الزهد» و«حلية الأولياء».

الآيات الكريمة والحديث الشريف مذكورة بنصّها ومصدرها كما طُلب.

## ملاحظات تقنية

- الخطوط تُحمّل من Google Fonts (Alexandria و Amiri)، لذا يلزم اتصال بالإنترنت لأفضل مظهر.
  يوجد بديل نظامي (Tahoma / Arial) إذا تعذّر التحميل.
- GSAP محفوظ محليًا داخل `js/vendor/`، لكن بقية المشروع يعمل حتى لو تعذّر تحميله (يظهر العرض بدون حركات).
- التصميم متجاوب بالكامل مع الشاشات المكتبية والتابلت والجوال، ويراعي تقليل الحركة.
